## The Test

A system is AGI if and only if:

```
1. It can observe reality
2. It can generate competing hypotheses
3. It can attack those hypotheses with evidence
4. It can update its beliefs based on what survives
5. It can declare what it does not know
6. It is constrained by domain law
7. It is constrained by constitutional floors (F1-F13)
8. It does not claim certainty it does not have
```

If any of these are absent, the system is not AGI.
It may be intelligent. It may be useful.
But it is not AGI.
