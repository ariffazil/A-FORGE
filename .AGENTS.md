## Key Entrypoints (For Agents)

### HTTP Server
```bash
npm run build && node dist/src/server.ts
# Listens on port 7071
# Endpoints: /agent/*, /approval/*, /vault/*, /health, /mcp*
```

### CLI (Agent Commands)
```bash
npm run build && node dist/src/cli.ts <command>
# Commands: approve, reject, replay, execute-plan, vault-query
```

### MCP Server (Stdio)
```bash
npm run build && node dist/src/mcp/cli.js serve --transport stdio
# Exposes 13 arifOS governance tools via MCP
```

## Quick Start for Agents

### 1. Understand the Request Flow
```
HTTP Request → server.ts (middleware gates) → router factory (typed) → handler
                ↓
            ApprovalBoundary (F3–F13 check)
                ↓
            Tool Execution (governance.ts)
                ↓
            VAULT999 Seal + Response
```

### 2. Make Changes Safely
- **Typed parsers first:** Edit `src/approval/filterParsing.ts` for validation logic
- **Routes second:** Add new handlers to appropriate router factory in `src/routes/`
- **Composition last:** Mount router in `server.ts` via `app.use()`

### 3. Validate
```bash
npm run build                # Compile TypeScript
npm test                     # Run 7 unit tests (node:test)
curl http://localhost:7071/health  # Health check
```
