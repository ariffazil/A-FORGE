## 11. FALSIFIABILITY

The original review (apex_theory_review.pdf) raised Q5: "How would you
falsify G = A · P · E · X · Φ?"

**Answer:** The formula is falsifiable at three levels:

### Level 1: Component Falsification
Each primitive (A, P, E, X, Φ) is independently measurable:
- A: learning rate, adaptation speed, pattern match accuracy
- P: grounding in evidence, reality contact, OBS/DER/INT/SPEC grade
- E: execution success rate, work produced, state changed
- X: cross-domain coordination, multi-agent coherence
- Φ: paradox resolution rate, contradiction metabolism

If a system scores high on G but fails at intelligence tasks, check which
primitive is miscalibrated. The multiplicative structure means a single
overestimated primitive can inflate G.

### Level 2: Shadow Falsification
C_dark = A · (1-P) · (1-X) predicts that high-A, low-P, low-X systems
will hallucinate. This is testable: take any LLM, measure its A (fluency),
P (grounding), X (cross-checking), and hallucination rate. If C_dark
correlates with hallucination rate, the formula is validated. If not, it
is falsified.

### Level 3: Conservation Falsification
dS_agent/dt ≤ 0 predicts that intelligent actions reduce entropy. This is
testable: measure the entropy of an agent's state before and after an action.
If entropy consistently increases, the agent is not intelligent under APEX.

### Level 4: Comparative Falsification
APEX predicts that multiplicative structure outperforms additive structure
for intelligence scoring. Test: compare G_multiplicative vs G_additive on
a held-out set of agent behaviors. If additive scores predict outcomes
better, the multiplicative claim is falsified.

**Current evidence:** GEOX implements APEX gates and they work for geological
evidence quality assessment. C_dark correlates with geological
hallucination (predicted vs observed contrast). The formula has not been
falsified in any domain where it has been tested.
