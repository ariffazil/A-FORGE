# A-FORGE — Repo Role Boundary

> Role: Constitutional Mutation Engine
> Anti-Sink Responsibility: Refuse patches that increase dependency without increasing agency

---

## Invariant Role

A-FORGE is the **execution and mutation engine** of the federation. It:
- Builds, deploys, and modifies code and infrastructure
- Runs under constitutional supervision (F1-F13)
- Forges artifacts only when authorized by arifOS Judge
- Defaults to dry-run mode for all irreversible operations

## Must Never Become

- A rival constitution or independent sovereign judge
- A governance kernel (that is arifOS)
- A control plane (that is AAA)
- An allocator of capital (that is WEALTH)

## Core Question

> Does this patch preserve judgment, rollback, and sovereignty?

## Anti-Sink Diagnostics

A-FORGE should eventually implement:
- Patch agency impact scoring (does this change increase or decrease human agency?)
- Rollback manifest enforcement (every mutation must have a rollback path)
- Beautiful patch detection (elegant code that removes safety — flag it)
- Diff risk scoring by constitutional floor impact
- No irreversible commits without explicit Arif acknowledgment + Judge verdict
