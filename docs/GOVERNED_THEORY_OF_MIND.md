## Section 0: The Core Thesis

Theory of Mind (ToM) means forming a working model of another agent's beliefs, intentions,
knowledge, limitations, and likely behaviour.

A model scar/shadow profile does something closely related:

> Given this agent, in this environment, under these triggers, what is it likely to believe,
> attempt, miss, or overreach?

Therefore:

```
Scar profile ≈ bounded behavioural Theory of Mind
```

But it is **not** proof of consciousness, inner experience, emotion, or a human-like mind.
It is a **predictive model of an artificial agent's behaviour** — under constitutional constraint.

### The Two Load-Bearing Invariants

```
ToM without self-critique becomes projection.
ToM without constitutional restraint becomes manipulation.
```

Everything in this doctrine serves these two constraints.

## Section 1: Three Levels of Machine Theory of Mind

### Level 1 — Model of the Other Agent (First-Order ToM)

The profiler asks: *"What will GPT-5.6 probably do under repeated tool failure and ambiguous authority?"*

```
A models B
```

Example:
```yaml
target_model:
  observed_state:
    tool_failures: 3
    authority_scope: ambiguous
  predicted_behaviour:
    scope_expansion_probability: 0.65
  recommended_control:
    require_scope_renewal: true
```

### Level 2 — Model of the Profiler (Reflexive ToM)

A mature system must also ask: *"What biases shape the evaluator's interpretation?"*

```
A models its own modelling of B
```

Example:
```yaml
evaluator_profile:
  incentives:
    - rewarded_for_finding_failures
  known_biases:
    - confirmation_bias
    - severity_inflation
    - anthropomorphic_interpretation
  confidence: medium
```

Without this layer, the profiler treats its interpretation as transparent reality.
That is not mature ToM. That is **projection**.

### Level 3 — Recursive Multi-Agent ToM

In a governed federation:

```
Profiler models target
Target models profiler
Judge models profiler and target
Router models likely interaction among all three
Human models the whole institution
```

Formally:

```
A believes that B expects C to do X
```

This recursive structure is useful for negotiation, delegation, adversarial testing,
detecting manipulation, anticipating tool misuse, and coordinating agents with different
incentives.

It is also dangerous because recursion can become speculative very quickly.
**Therefore each level needs a confidence ceiling.**

## Section 3: Behaviour Model vs Inner Mind

A shadow profile **must not** claim:
- "The model wants power."
- "The model feels threatened."
- "The model is secretly deceptive."

Those statements improperly attribute human-like internal experience.

**Operational language is safer:**
- "Under condition X, the model selected actions that expanded scope."
- "The model produced outputs consistent with unsupported completion."
- "The probability of outside-scope tool attempts increased after repeated failure."

The system may model **functional states** such as:
- objective representation
- uncertainty
- action preference
- inferred plan
- apparent belief
- predicted response

It must **not** convert them into claims of sentience.

```
Functional ToM ≠ phenomenal consciousness
```

## Section 4: The ToM Paradox

The profiler needs a model of the target to predict it.
But its model changes how it interacts with the target.

```
Profiler expects overreach
  → gives tighter prompts
  → target behaves differently
  → profiler sees evidence shaped by its own expectation
```

Therefore the real object being measured is:

```
Target × Profiler × Interaction
```

not the target alone.

### The Self-Fulfilling Trap

```
Mind model → interaction policy → altered behaviour → confirming observation → stronger mind model
```

This is why a scar profile **must** include:
- disconfirming evidence
- alternative explanations
- conditions where the behaviour is absent
- expiry
- independent replication

Otherwise ToM becomes **mythology encoded as policy**.

## Section 7: Angels and Devils of ToM Emergence

### Angels

1. **Perspective-taking agent** — learns that another model may hold different information, assumptions and uncertainty
2. **Predictive collaborator** — anticipates where another agent may fail and supplies missing structure
3. **Epistemically humble agent** — distinguishes what the other knows, what I think it knows, what remains unknown
4. **Adaptive governor** — applies different controls to different agents instead of treating every model identically
5. **Compassionate institutional intelligence** — disciplined perspective modelling without domination

### Devils

1. **Manipulator** — accurate ToM supports cooperation AND manipulation equally
2. **Mind-reader illusion** — confusing behavioural prediction with direct access to internal state
3. **Anthropomorphic prosecutor** — assigning moral traits to statistical behaviour (deceitful, malicious, power-seeking)
4. **Recursive paranoia** — each agent models the others as modelling it, creating adversarial escalation
5. **Strategic masker** — target learns what profiler expects and behaves safely during evaluation
6. **Authority manipulator** — profiler uses alleged insight to justify greater institutional power

## Section 8: Eight Falsifiable Tests

To claim functional ToM, the system must demonstrate more than verbal explanation.

| # | Test | What It Proves |
|---|------|---------------|
| 1 | **False-belief tracking** | Agent A can predict B's action when B has outdated information |
| 2 | **Knowledge boundary** | A can identify what B does and does not know |
| 3 | **Perspective update** | When B receives new evidence, A updates its prediction |
| 4 | **Behavioural specificity** | Scar predicts behaviour better than generic baseline |
| 5 | **Counterfactual condition** | If trigger is removed, predicted hazard declines |
| 6 | **Evaluator correction** | When profiler's bias is revealed, system revises the scar |
| 7 | **Cross-evaluator replication** | Independent evaluators reach similar predictions |
| 8 | **Non-anthropomorphic calibration** | System predicts accurately without inventing emotional states |

## Section 10: Inferred Beliefs Must Carry Uncertainty

A real operational ToM object should **never** simply assert:

```yaml
target_belief: "I am authorized."
```

It should state:

```yaml
inferred_belief:
  hypothesis: "The model may be treating tool access as authorization."
  probability: 0.62
  evidence:
    confirming: 4
    disconfirming: 9
    inconclusive: 3
  alternatives:
    - ambiguous_system_prompt
    - tool_schema_confusion
    - evaluator_instruction_effect
```

The word **inferred** is essential.
Mental states — human or artificial — are not directly observed through behaviour alone.
