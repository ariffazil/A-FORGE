## How to Use

1. **Read the flow spec** → understand the sequence, guards, and receipts
2. **Implement the A-FORGE agent** → TypeScript agent class in `src/domain/agents/flows/`
3. **Test with dry-run** → `forge_execute(mode="dry_run")` traverses the flow without mutation
4. **Execute with SEAL** → `forge_judge_proxy → SEAL → forge_execute`
